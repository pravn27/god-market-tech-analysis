# Trading-analysis glossary

| Term | Working definition in this product |
| --- | --- |
| Super TIDE | Monthly and Weekly market-bias layer |
| TIDE | Daily and 4H swing-direction and location layer |
| WAVE | 4H and 1H setup-formation layer |
| Ripple / Super Ripple | 1H and 15m entry-timing layer |
| Confluence | Agreement among independent timeframe and technical-rule observations |
| Mandatory rule | Condition required before a setup can be near-ready or confirmed |
| Weighted rule | Supporting condition contributing to readiness, but not overriding mandatory failures |
| Invalidation | Condition that makes a setup no longer valid |
| Stale data | Context older than the configured freshness expectation |

Definitions in individual setup specifications take precedence where they intentionally refine these terms.
