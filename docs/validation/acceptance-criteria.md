# Acceptance and Definition of Done

## Definition of Ready

A feature is ready to build only when:

- its product outcome and non-goals are documented;
- inputs, outputs, failure behaviour, and acceptance criteria are explicit;
- any TradingView/MCP dependency is confirmed or bounded by a spike;
- test data or replay scenarios are identified; and
- no unresolved decision would materially change its design.

## Definition of Done

A feature is done only when:

- the approved specification is implemented;
- automated tests cover the deterministic logic;
- integration behaviour is tested where applicable;
- manual verification against TradingView chart evidence is recorded;
- failure and stale-data states are visible and safe;
- documentation and configuration examples are updated; and
- the feature has a release note and known limitations recorded.

## Evidence required

For each completed feature, retain links or files for the specification, test result, manual chart-verification record, and release note.
